# Talento Tech - Pre-delivery


This is a Command Line Interface (CLI) application developed with **Node.js** that allows you to manage products directly from the terminal by consuming data from the **Fake Store API**.


## 🚀 Technologies Used


* **Node.js** (Runtime environment)
* **JavaScript** (ES Modules)
* **Fetch API** (Asynchronous requests)
* **Fake Store API** (Data source)
* **Mocha & Chai** (Testing)


---


## 📦 Installation & Usage


1.  **Install dependencies:**
    ```bash
    npm install
    ```


2.  **Run the application:**
    ```bash
    npm run start
    ```


---


## ⚙️ Available Commands (Usage)


You can interact with the API using the following commands:


* **Get all products:**
    ```bash
    npm run start GET products
    ```


* **Get a product by ID:**
    ```bash
    npm run start GET products/7
    ```


* **Create a new product:**
    ```bash
    npm run start POST products "Remera negra" 29.99 "men's clothing"
    ```


* **Delete a product:**
    ```bash
    npm run start DELETE products/7
    ```


---


## 🧪 Testing


To ensure the correct operation of the logic, unit tests were implemented using **Mocha**.


Run the tests with the following command:
